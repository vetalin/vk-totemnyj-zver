# Публикация VK мини-приложения

Этот скилл помогает подготовить и опубликовать мини-приложение ВКонтакте. Процесс состоит из двух основных этапов: заполнение страницы "Информация" и страницы "Оформление" в кабинете разработчика VK.

## Общий план работы

1. Получить от пользователя проект (ссылка на репо или локальная папка)
2. Изучить проект — прочитать README, package.json, структуру компонентов
3. Запустить приложение локально, чтобы увидеть интерфейс
4. Сделать скриншоты ключевых экранов
5. Подготовить текстовые описания на основе функционала
6. Создать/подготовить иконки и изображения строго по размерам
7. Зайти в кабинет разработчика VK и заполнить все поля
8. Показать результат пользователю и получить подтверждение перед отправкой на модерацию

## Шаг 1: Изучение проекта

Перед заполнением полей нужно хорошо понять приложение:

- Прочитай README, package.json, или другие файлы с описанием проекта
- Посмотри структуру компонентов и экранов
- Определи целевую аудиторию и основное назначение
- Запусти проект локально (`npm run dev` или аналог) и посмотри интерфейс в браузере
- Сделай скриншоты всех ключевых экранов приложения

## Шаг 2: Страница "Информация"

URL страницы: `https://dev.vk.com/ru/admin/app-settings/{APP_ID}/info`
Документация: `https://dev.vk.com/ru/mini-apps/settings/general/information`

### Все поля и их требования:

### Название приложения
- Как его видят пользователи в каталоге, сниппетах и других местах ВКонтакте
- Допустимые символы: буквы, цифры, дефисы, пробелы, двоеточия и тире
- Эмодзи использовать НЕЛЬЗЯ
- Длина: от 3 до 34 символов
- Должно отражать суть приложения, быть понятным и запоминающимся

### Категория
- Выбирается из выпадающего списка
- Учитывается при составлении подборок в каталоге
- Отображается в подборках и сниппетах
- ВАЖНО: после публикации в каталоге категорию можно изменить только через Поддержку VK — выбирай внимательно сразу

### Описание
- Видно на экране «О приложении» в каталоге и во всплывающей карточке каталога плагинов для сообществ
- Максимальная длина: 2 000 символов
- Подробное описание функционала, для кого предназначено, как пользоваться

### Краткое описание
- Показывается во всплывающей карточке мини-приложения и в подборках каталога
- Также используется в каталоге плагинов для сообществ
- Максимальная длина: 128 символов
- Если не заполнено — платформа подставит текст из полного Описания

### Короткий адрес
- Часть URL после `https://vk.com/`
- По умолчанию адрес выглядит как `https://vk.com/app12357`
- Допустимы только латинские символы, подчёркивания и цифры
- Длина: от 5 до 32 символов
- Изменить можно после публикации в каталоге
- Важно для продвижения — выбирай запоминающийся адрес

### Официальное сообщество
- Выбирается из списка сообществ, где создатель является администратором
- Приложение будет отображаться в выбранном сообществе в разделе «Приложения»
- Позволяет отправлять ЛС пользователям от имени сообщества (важно для продвижения)
- Сменить сообщество можно раз в год после публикации. До публикации — менять можно свободно

### Запуск приложения из сообщества
- Когда включено — мини-приложение можно добавить в сообщество и запускать оттуда
- В сообщество можно добавить только одно мини-приложение и до пяти плагинов

### Название кнопки
- Название кнопки на карточке приложения в сообществе
- Можно переопределить в настройках сообщества

### Запуск на iOS (Company Name)
- Для публикации в каталоге на iOS или запуска в WebView вне каталога
- Для юридических лиц — название компании из Кабинета выплат
- Для ИП и самозанятых — ФИО
- Допустимы: буквы (латиница и кириллица), цифры, пробелы и символы: . , « » -
- Если не заполнено — мини-приложение на iOS будет открываться в мобильном браузере

### Как писать описания

Описание должно быть на русском языке, без грамматических ошибок, без кликбейта и чрезмерных обещаний. Конкретно описывай, что пользователь может делать в приложении. Не упоминай другие платформы.

**Пример краткого описания (до 128 символов):**
"Удобный планировщик задач с напоминаниями. Создавай списки и следи за прогрессом прямо во ВКонтакте."

**Пример полного описания (до 2000 символов):**
"Приложение для планирования задач, созданное специально для ВКонтакте. Основные возможности: создание задач и списков дел, установка дедлайнов и напоминаний, отслеживание прогресса, совместная работа с друзьями. Приложение интегрировано с уведомлениями ВКонтакте, чтобы вы не забывали о важных делах."

## Шаг 3: Страница "Оформление"

URL страницы: `https://dev.vk.com/ru/admin/app-settings/{APP_ID}/design`
Документация: `https://dev.vk.com/ru/mini-apps/settings/general/design`

Здесь настраиваются иконки, изображения и видео для каталога, экрана запуска, сниппетов и других экранов.

### Иконки

#### Универсальная иконка (ОБЯЗАТЕЛЬНА)
- Размер: **576×576 px** (строго!)
- Формат: JPG, PNG
- По умолчанию из неё автоматически создаются иконки других размеров
- Это главная иконка — от неё зависят все остальные

#### Иконка для каталога и сниппетов
- Размер: **278×278 px**
- Формат: JPG, PNG
- Используется в подборках каталога и в сниппетах в сообщениях
- Если не загружена — создаётся автоматически из универсальной иконки

#### Маленькая иконка
- Размер: **150×150 px**
- Формат: JPG, PNG
- Используется на экране запуска, в сообщениях и уведомлениях
- Если не загружена — создаётся автоматически из универсальной иконки

#### Фавикон
- Размер: **32×32 px**
- Формат: JPG, PNG, GIF
- Максимальный размер файла: **50 КБ**
- Используется для вкладки десктопного браузера
- НЕ создаётся автоматически — нужно загрузить вручную

#### Цвет фона иконок
- Цвет основы иконки в каталоге мобильного приложения
- Выбирается автоматически по доминирующему цвету иконки
- Можно переопределить вручную

### Изображения

#### Большой сниппет
- Размер: **1120×630 px**
- Формат: JPG, PNG, GIF
- Отображается при публикации ссылки на приложение на стене
- Также нужно выбрать **Название кнопки** в сниппете (например «Перейти», «Связаться», «Открыть»)

#### Скриншоты
- Размер: **600×1200 px** (вертикальная ориентация)
- Формат: JPG, PNG, GIF
- Отображаются: во всплывающей карточке, на экране «О приложении» в каталоге мини-приложений и плагинов
- Используй изображения одинакового размера и ориентации
- ВАЖНО: при смене ориентации загруженные изображения удаляются без возможности восстановления

### Баннеры (доступны после публикации в каталоге)

#### Баннер для Android и iOS
- Размер: **800×1068 px**
- Формат: JPEG, PNG
- Показывается в подборках каталога мобильного приложения
- Пока не загрузился — показывается прямоугольник цвета из настройки «Цвет заглушки»
- После загрузки нельзя очистить, можно только заменить

#### Баннер для десктопной версии сайта
- Размер: **1050×630 px**
- Формат: JPEG, PNG
- Используется в карусели баннеров каталога десктопной версии
- После загрузки нельзя очистить, можно только заменить

#### Краткое описание для баннеров
- Текст на баннерах (десктоп и мобильные)
- Максимальная длина: **48 символов**
- Допустимы любые символы, включая эмодзи
- Можно выбрать цвет текста: Тёмный или Светлый (для контраста с фоном баннера)

### Экран запуска
- Иконка в формате **Lottie** (анимированная)
- Можно настроить цвет фона и включить анимацию

## Шаг 4: Подготовка изображений

### Сводная таблица размеров

| Элемент | Размер (px) | Формат | Примечание |
|---|---|---|---|
| Универсальная иконка | 576×576 | JPG, PNG | Обязательна, основа для других |
| Иконка каталога | 278×278 | JPG, PNG | Авто из универсальной |
| Маленькая иконка | 150×150 | JPG, PNG | Авто из универсальной |
| Фавикон | 32×32 | JPG, PNG, GIF | До 50 КБ, загрузить вручную |
| Большой сниппет | 1120×630 | JPG, PNG, GIF | Для ссылки на стене |
| Скриншоты | 600×1200 | JPG, PNG, GIF | Вертикальная ориентация |
| Баннер Android/iOS | 800×1068 | JPEG, PNG | После публикации |
| Баннер десктоп | 1050×630 | JPEG, PNG | После публикации |

### Создание изображений через Python (Pillow)

Для подготовки изображений точных размеров используй Pillow:

```python
from PIL import Image

# Универсальная иконка 576x576
img = Image.open("source_icon.png")
img = img.resize((576, 576), Image.LANCZOS)
img.save("icon_576x576.png")

# Иконка для каталога 278x278
img_catalog = img.resize((278, 278), Image.LANCZOS)
img_catalog.save("icon_278x278.png")

# Маленькая иконка 150x150
img_small = img.resize((150, 150), Image.LANCZOS)
img_small.save("icon_150x150.png")

# Фавикон 32x32
img_favicon = img.resize((32, 32), Image.LANCZOS)
img_favicon.save("favicon_32x32.png")

# Большой сниппет 1120x630
snippet = Image.open("screenshot.png")
snippet = snippet.resize((1120, 630), Image.LANCZOS)
snippet.save("snippet_1120x630.png")

# Скриншот 600x1200
screenshot = Image.open("app_screen.png")
screenshot = screenshot.resize((600, 1200), Image.LANCZOS)
screenshot.save("screenshot_600x1200.png")
```

Все изображения ОБЯЗАТЕЛЬНО должны быть ровно указанных размеров — отклонение даже на 1 пиксель может привести к отказу на модерации.

Для скриншотов лучше не просто ресайзить, а использовать кроп с сохранением пропорций, чтобы не было искажений. Скриншоты должны соответствовать реальному приложению.

## Шаг 5: Заполнение через браузер

Когда все материалы подготовлены:

1. Перейди на страницу "Информация" в кабинете разработчика
2. Заполни все текстовые поля (название, описания, категорию, короткий адрес)
3. Перейди на страницу "Оформление"
4. Загрузи все подготовленные изображения в соответствующие поля
5. Проверь, что всё отображается корректно
6. Сделай скриншот результата и покажи пользователю
7. Получи подтверждение перед отправкой на модерацию

При работе в браузере:
- Используй `read_page` для чтения текущих полей формы
- Используй `find` для поиска полей ввода и кнопок загрузки
- Используй `file_upload` для загрузки изображений в соответствующие input-элементы
- После заполнения каждой страницы сделай скриншот для подтверждения

## Шаг 6: Проверка перед модерацией

Перед отправкой убедись:
- Все обязательные поля заполнены
- Название: 3-34 символа, без эмодзи
- Описание: до 2000 символов, отражает реальный функционал
- Краткое описание: до 128 символов
- Категория выбрана корректно (после публикации не изменить без поддержки)
- Универсальная иконка загружена (576×576)
- Фавикон загружен вручную (32×32, до 50 КБ)
- Скриншоты загружены (600×1200), соответствуют реальному приложению
- Большой сниппет загружен (1120×630)
- Нет нарушений правил ВКонтакте
- Покажи пользователю финальный результат и получи подтверждение

## Частые причины отказа в модерации

- Скриншоты не соответствуют реальному приложению
- Неправильные размеры изображений (даже отклонение на 1 px)
- Описание не соответствует функционалу
- Нет политики конфиденциальности
- Приложение не работает или работает с ошибками
- Контент нарушает правила ВКонтакте
- Приложение дублирует функционал существующих приложений без добавленной ценности
- Нет возможности удалить данные пользователя по запросу
