# Твой тотемный зверь — Спецификация

> Документ для Designer и Developer. Все данные из исходников (`/tmp/vk-totem-tmp/`).

---

## 1. Концепция и видение

**Что это:** Квиз-приложение в формате VK Mini App, которое определяет тотемное животное пользователя по 5 вопросам.

**Суть:** Пользователь отвечает на 5 вопросов о своём характере и поведении. По majority-голосованию определяется его тотемное животное из 4 вариантов: Волк (🔥), Медведь (🌍), Орёл (💨), Дельфин (💧).

**Текущий tone of voice:** Простой, немного игривый ("Узнай тотемного зверя", "Пройди снова"). Целевая аудитория — пользователи ВКонтакте 16–35 лет.

**Ограничения текущей версии:**
- Только тёмная тема (жёстко задано `colorScheme="dark"`)
- Нет анимаций и переходов между экранами
- Нет возможности "переиграть" без полного рестарта
- Нет сохранения результата / истории

## 3. Функциональная спецификация

### 3.1 Экраны

#### Screen 1: StartScreen (`id="start"`)
- Заголовок: "Твой тотемный зверь" с эмодзи 🦁
- Подзаголовок: "Узнай, какое животное символизирует твой дух"
- Карточка с описанием теста
- Эмодзи-ряд: `🐺 🐻 🦅 🐬`
- CTA-кнопка: "Узнать тотемного зверя" → переход на QuizScreen

#### Screen 2: QuizScreen (`id="quiz"`)
- Прогресс-бар (0–100%, шаг 20% за вопрос)
- Текст: "Вопрос X из 5"
- Текст вопроса (Title level="2")
- 4 Card с кнопками-ответами (mode="primary")
- При клике → `onAnswer(element)` → либо следующий вопрос, либо переход на ResultScreen

#### Screen 3: ResultScreen (`id="result"`)
- Эмодзи животного (96px)
- Название: "Волк" / "Медведь" / "Орёл" / "Дельфин"
- Карточка с описанием характера
- Кнопка "Поделиться результатом" (mode="secondary")
- Кнопка "Пройти снова" (mode="primary") → возврат на StartScreen

```typescript
// simple majority — побеждает элемент с наибольшим количеством ответов

```

## 4. UX анализ (текущее состояние)

### 4.1 Сильные стороны
- Простая и понятная структура: 3 клика = результат
- Минимальное количество экранов (нет лишних шагов)
- Наглядный прогресс-бар в квизе
- Кнопка "Пройти снова" сразу на ResultScreen

### 4.2 Проблемы и улучшения

#### 🔴 Критические
1. **Жёсткая тёмная тема** — пользователи VK с включённой светлой темой увидят неправильное отображение. VKUI поддерживает `colorScheme={undefined}` с автоопределением.
2. **Share API использует устаревший `VK.Share`** — `window.VK.Share.click()` не работает в новых версиях VK Mini App. Рекомендуется использовать `VKWebAppShare` из `@vkontakte/vk-bridge`.

#### 🟡 Важные
1. **Нет анимаций** — переходы между экранами мгновенные, без плавности. Добавить CSS transitions или VKUI-animations.
2. **Нет звуков/вибрации** — для квиза это упущенная возможность вовлечения. `bridge.send('VKWebAppFlashSetLevel', { level: 1 })` для feedback.
3. **Нет экрана "loading"** — при первом запуске VK Bridge может не успеть инициализироваться.
4. **Нет индикации выбранного ответа** — пользователь не видит, что он уже ответил на вопрос.

#### 🟢 Желательные
1. **Анимированное появление результата** — эмодзи животного может "появиться" с эффектом.
2. **Ранг/уровень тотема** — например, "Волк-вожак" vs "Волк-одиночка" в зависимости от распределения ответов.
3. **Интересный факт об animal** — добавить 2–3 дополнительных факта под основным описанием.
4. **Показывать промежуточные результаты** — после каждого ответа слегка менять "倾向" в подсказке.
5. **Таймер ответа** — ограничение по времени (10 сек) добавит геймификации.
6. **Нет повторного прохождения с другого аккаунта** — результат не сохраняется и не передаётся через VK API.

## 5. Геймификация

### 5.1 Текущее состояние
- Простой majority-подсчёт
- Нет уровней, рангов, очков
- Нет скрытых элементов ("разблокируй своего тотема")
- Нет прогресса или "коллекции"

### 5.2 Предложения по геймификации

#### Ранговая система (предложение)
```typescript
// По соотношению ответов
const dominantRatio = maxCount / totalAnswers; // 0.2 - 1.0

if (dominantRatio >= 0.8) → "Чистый [Тотем]"      // Все 5 ответов совпали
if (dominantRatio >= 0.6) → "[Тотем]-вожак"       // 3-4 из 5
if (dominantRatio >= 0.4) → "[Тотем]-искатель"     // 2-3 из 5
if (dominantRatio < 0.4)  → "Душа-хамелеон"        // Ничья или близко
```

#### Элемент неожиданности
- Скрытая комбинация: если все 5 ответов разные → бонусный экран "Редкий зверь — Феникс 🦅🔥" (уникальный кейс)
- Анимация "раскрытия" вместо мгновенного показа результата

#### Пройти снова
- Кнопка "Пройти снова" есть, но работает через полный рестарт (handleRestart)
- Нет возможности изменить 1 ответ — полный сброс

## 8. Рекомендации для Designer

1. **Визуальный стиль:** Минималистичный, но с акцентом на элемент-тему. Каждый тотем — свой цвет фона или градиент карточки.
2. **Эмодзи → SVG:** Заменить 🐺🐻🦅🐬 на стилизованные SVG-иллюстрации животных.
3. **Анимации:** Slide-переходы между экранами, scale-in для результата, pulse для выбранного ответа.
4. **Градиенты элементов:**
   - Fire 🔥 → красно-оранжевый градиент
   - Earth 🌍 → коричнево-зелёный
   - Air 💨 → голубой/белый
   - Water 💧 → синий/бирюзовый
5. **Прогресс:** Визуальный прогресс не только как bar, но и как "путь" с иконками животных.
